NOAA anomaly forecasting

Climate Anomaly Forecaster

Run the final NOAA monthly temperature-anomaly setup selected from the notebook experiments.

1. Estimate normal An 18-year rolling climatology estimates the usual temperature for the target month.
2. Model the residual The selected LSTM predicts the leftover anomaly after the monthly baseline is removed.
3. Use recent signals The default run uses sparse temperature lags, 48-month recency weighting, and current ENSO.

How To Read Results

The forecast number is a temperature anomaly in degrees Celsius compared with the normal for that month. The plot compares observed anomalies against predictions over the held-out test period.

Negative = colder than normal 0 = near normal Positive = hotter than normal
